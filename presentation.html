Slide 01 • Overview

Real-Time Train Movement Tracker

Live Telemetry, Geographic Track Visualisation & WebSocket Streaming

A full-stack, distributed GIS application designed to track and visually animate Indian Railways trains with sub-meter track precision along physical railway routes using live telemetry, Haversine interpolation, and WebSocket pub/sub streaming.

⚡ Java 27 & Spring Boot 3

Reactive back-end services, scheduled polling engines, and STOMP message brokers.

🗺️ Leaflet & OpenRailwayMap

Multi-layered spatial maps displaying actual physical tracks, switches, and electrified rails.

📡 Live Telemetry Stream

Real-time speeds, departure stations, next halts, and arrival delay status.

Slide 02 • Problem Statement

Why Train Movement Tracking?

Overcoming Limitations in Existing Railway Enquiry Systems

Traditional Enquiry Portals (NTES / SMS) Train Tracker Platform
Text Only: Displays station name and timestamp without spatial context. Physical Track Visualisation: Train marker animates directly on OpenRailwayMap rails.
Infrequent Updates: Information logged only when train stops at manned stations. Continuous Streaming: WebSocket pub/sub pushes dynamic coordinate updates.
No Real Position: Commuters cannot see where the train is between stations. Haversine Interpolation: Calculates exact location along polyline curves.
Heavy Server Strain: Millions of clients polling HTTP endpoints. Selective Subscriptions: Clients receive push events only for active trains.
Slide 03 • Architecture

System Architecture

End-to-End Distributed Data Flow

1. Ingestion Layer

RailRadar Live API: Periodically polls live running statuses, delay minutes, and comprehensive route geometries.

2. Processing & Persistence

Spring Boot 3 + MySQL 8: Normalises JSON, handles orthogonal track snapping, persists historical telemetry, and handles quota fallbacks.

3. Streaming & Presentation

STOMP over SockJS + Leaflet: Pushes live coordinates to active browser subscribers and renders animated beacons on tracks.

Slide 04 • Technical Innovations

Core Technical Innovations

Algorithms for Spatial Accuracy & Performance

📐 Haversine Multi-Segment Interpolation

Computes geodesic distance across hundreds of railway coordinates. Translates journey progress fraction into sub-meter accurate coordinates along curved tracks.

🎯 Orthogonal Track Snapping

Projects reported station GPS coordinates onto the nearest track vector segment within a 500m tolerance threshold, eliminating visual GPS drift.

🔄 Zero-Downtime Multi-Train Switching

Users can change trains without tearing down the underlying WebSocket connection. Subscriptions switch dynamically in 0 ms.

✨ Smooth LERP Marker Animation

Linear interpolation (LERP) over 800ms frames glides the train marker along bearing angles (θ°) matching track orientation.

Slide 05 • Resilience Engine

Resilience & Quota-Aware Fallback

Handling Third-Party Rate Limits Without Service Halts

External transit APIs enforce strict monthly call limits (e.g., HTTP 429 Too Many Requests). The Train Tracker incorporates an intelligent dual-mode engine:

🟢 Live Provider Mode

Active when external API quotas are valid. Directly ingests GPS, live delay departures, and actual station timestamps.

🔵 Smart Kinematic Fallback Mode

Seamlessly takes over when the API is throttled or offline. Computes realistic kinematic progression along the loaded high-resolution railway route.
